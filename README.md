# Comet Connect 

**Comet Connect** is a browser tool that helps you "teleport" your AI conversations. It lets you save a chat from one AI (like ChatGPT) and move it into another (like Claude or Gemini) so you never lose your context.

### ✨ What It Does

* **💾 Save Your Chats:** Download your entire conversation history with one click.
* **🛡️ Keeps You Safe:** Automatically removes sensitive info like emails, phone numbers, and credit cards before saving.
* **🚀 Auto-Transfer:** Automatically types your old conversation into a new AI window so you can pick up exactly where you left off.
* **⛔ Security Lock:** The tool automatically turns itself off if you visit a banking or password site.

---

### 🛠️ How to Set It Up (One-Time Setup)

Since this is a private tool, you need to add it to Chrome manually. It only takes 30 seconds:

1.  **Download the Code:** Download this folder to your computer (and unzip it if needed).
2.  **Open Extensions:** Open Google Chrome and type `chrome://extensions` in the address bar.
3.  **Developer Mode:** In the top right corner, turn on the switch that says **"Developer mode"**.
4.  **Load It:** Click the button that says **"Load unpacked"**.
5.  **Select Folder:** Select the folder where you saved the code.

*That's it! You should now see the Comet Connect icon in your browser.*

---

### 🎮 How to Use It

#### Step 1: Saving a Chat (Export)
1.  Go to the AI chat you want to save.
2.  Scroll to the top of the conversation.
3.  Click the **Orange Button (📡)** in the bottom right corner.
4.  The tool will clean the chat and download a file to your computer.

#### Step 2: Moving the Chat (Import)
1.  Open a new AI window (e.g., open a fresh ChatGPT or Gemini tab).
2.  Click the **Green Button (📥)** in the bottom right corner.
3.  Select the file you downloaded in Step 1.
4.  **Let go of the mouse!** The tool will automatically type out your history for you.
